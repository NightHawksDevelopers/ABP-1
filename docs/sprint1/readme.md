|             Critério             | Descrição                                                                                                                                                           |

| Protótipo Aprovado | Layout inicial (Figma) da estrutura do site disponível para consulta. |

##  DoD - Definition of Done <a id="dod"></a>

|                 Critério                 | Descrição                                                                            |
| :--------------------------------------: | ------------------------------------------------------------------------------------ |

|       Revisão e Deploy                | Código revisado, aprovado e build sem erros.                                         |
